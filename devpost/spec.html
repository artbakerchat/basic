How inputs, autonomous agents, time events, and UI coordinate in Unity:

Component Breakdown

ScentBeaconController.cs

Implements prd.md > Feature 1: Gaze-Directed Scent Beacon & Pathfinding.

Gaze Raycasting
Converts mouse position to world coordinates via Camera.main.ScreenToWorldPoint() and casts a 2D raycast against interactive layer masks.
Event Dispatch
Fires OnBeaconPlaced(Vector2 pos, TargetType type). If hovering over empty ground, safely drops input without interrupting ongoing flights.

BeeAgent.cs

Implements prd.md > Feature 1, Feature 2, and Feature 3.

Finite State Machine
Manages 4 states: Idle, FlyingToBeacon, Harvesting, and ReturningToHive.
Vector2 Steering + Sine Bob
Direct velocity towards target plus perpendicular oscillation Mathf.Sin(Time.time * freq) * amp creates natural insect float without navmesh baking.
Retargeting Rules
Mid-flight gaze shifts instantly redirect steering. Mid-harvest gaze shifts wait for current 2.5s coroutine before departing.
Inventory Tracking
Holds carried nectar. Automatically triggers ReturningToHive when nectar reaches 20/20 max capacity.

FlowerPatch.cs

Implements prd.md > Feature 2 and prd.md > Feature 4.

Nectar Dispenser
Yields +5 nectar per harvest. Manages blossom cooldown and temporary depletion states.
Dream Bloom Node
Holds references to a cyan Light2D and spore ParticleSystem. Toggled on/off during the 3 AM window.

HiveBase.cs

Implements prd.md > Feature 3: Hive Return & Resource Deposition.

Drop-Off Point
2D trigger collider at meadow center. Unloads the bee upon arrival, clearing bee inventory to 0.
Colony Resource Bank
Increments standardHoney and dreamDrops. Dispatches inventory change events to UI.

TimeEventManager.cs

Implements prd.md > Feature 4: Real-Time 3:00 AM Dream Bloom Event.

System Clock Evaluator
Evaluates DateTime.Now.Hour == 3 per second. Initiates the 45-second real-world countdown timer.
Atmospheric Director
Smoothly transitions global 2D lighting to deep midnight blue and commands dream blooms to uncurl and emit spores.

HUDManager.cs

Implements prd.md > Canvas HUD.

Live Clock & Banner
Updates Clock_Text with formatted local time. Toggles DreamEvent_Banner during the active window.
Slider & Score Panels
Smoothly animates Nectar_Slider fill and formats StandardHoney_Text and DreamNectar_Text.

Simplifications & Architectural Tradeoffs

Vector2 Steering vs. NavMesh
Zero package dependencies, no baking step, immediate organic bobbing bee-flight feel.
Session Memory vs. PlayerPrefs
Scores reset to 0 on launch to ensure an instantly reproducible test state for recording demo clips.
Mouse Raycast vs. Eye Tracking
Universal standard hardware access via Camera.main.ScreenToWorldPoint, accessible to all judges and platforms.
