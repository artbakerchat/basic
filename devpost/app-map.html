What Was Built

Beeplex is a 2D ambient bee foraging simulation built with Unity and C#. Rather than arcade stick controls, the player directs the bee indirectly through gaze-projected scent beacons. At 3:00 AM real time, a 45-second nocturnal Dream Bloom event transforms the meadow into deep midnight blue, activates cyan bioluminescent flora with rising spores, and allows harvesting rare Dream Drops.

The Action Route: From Gaze to Score

How one core action flows through the codebase:

Code Route Stops

Stop 1: Scent Beacon Projection Assets/Scripts/Bee/ScentBeaconController.cs

Anchor: HandleGazeRaycast(). Reads the mouse screen position, projects a 2D raycast through Camera.main.ScreenToWorldPoint(), and dispatches OnBeaconPlaced to draw the bee toward interactive colliders.

Stop 2: Autonomous Flight & Retargeting Assets/Scripts/Bee/BeeAgent.cs

Anchor: UpdateFlight() and HarvestRoutine(). Calculates Vector2 normalized steering toward the beacon, adds a perpendicular Mathf.Sin hover oscillation, and queues new gaze targets if the bee is actively siphoning nectar.

Stop 3: 3:00 AM Real-Time Director Assets/Scripts/Core/TimeEventManager.cs

Anchor: DreamBloomRoutine(). Triggers the 45-second event when DateTime.Now.Hour == 3 (or via the triggerTestEvent inspector toggle), dims ambient lighting to midnight blue, and activates cyan Light2D and spore emitters on dream blooms.

To Change This, Start Here

Bee Speed or Hover Wobble
Adjust flightSpeed, hoverFrequency, or hoverAmplitude in BeeAgent.cs.
Harvest Duration & Yield
Change siphon wait time in BeeAgent.cs > HarvestRoutine() or nectarYield in FlowerPatch.cs.
Event Duration & Testing
Modify eventDurationSeconds (default: 45s) or toggle triggerTestEvent in TimeEventManager.cs.

A Practice to Reuse

Decoupling Input from Agent Autonomy via Scent Beacons

Instead of directly manipulating character velocity from player input (which often creates rigid or tangled movement code), the input layer merely drops an abstract world-space beacon event (OnBeaconPlaced). The autonomous agent independently evaluates its own state machine (Idle, Flying, Harvesting) to decide how and when to respond.

Takeaway for your next AI project: When creating autonomous or emergent behavior, decouple player intention into objective signals in the world rather than hard-coding direct input into your creature's state logic.
