# Beeplex - Bee Foraging Simulator

An interactive bee foraging simulator where players control or manage a bee navigating through environments to scout, locate, and collect nectar, bringing it back to grow and sustain the hive.

Built as part of the **Devpost Learn: Build With AI: Basics** hackathon curriculum.

## Overview
- **Game Concept**: Scout environments, collect nectar, sustain the hive.
- **The Catch**: The elusive "dream nectar" only happens during the 3:00 AM window!
